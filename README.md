# GymFlow

Gerenciador de fichas de treino desenvolvido para organizar treinos,
exercícios e acompanhamento da rotina de musculação.

## Funcionalidades

- Criação de fichas de treino
- Organização por grupos musculares
- Catálogo de exercícios
- Configuração de séries, repetições, carga e descanso
- Edição de fichas
- Backup e restauração dos dados
- Filtros por região e grupo muscular
- Interface responsiva

## Tecnologias

- HTML
- CSS
- JavaScript
- LocalStorage
